# Accessibility Tips

Tips, tricks and best practices related to accessibility.

## Running it on local

1. Clone the project:

```shell
$ git clone https://github.com/Vranjan7077/accessibility-tips.git
```

2. Install the dependencies:

```shell
$ cd accessibility-tips
$ npm install
```

3. Run it on the local:

```shell
$ npm start
```

Open http://localhost:3000 in your browser to see it in action.
